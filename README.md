# Sprint_5
Тестирование сайта stellarburgers.education-services.ru разделено на 4 группы тестирования:
1. test_1_registration_in_site - содержит 4 теста: 
    1.1 проверка вывода ошибки при вводе пароля менее 6 символов
    1.2 проверка вывода ошибки при попытке регистрации с некорректной почтой
    1.3 проверка успешной регистрации
    1.4 проверка вывода ошибки при попытке регистрации с уже зарегистрированной почтой
2. test_2_logon_in_site - содержит 6 тестов:
    2.1-4 проверка перехода на страницу авторизации:
        - по ссылке "Личный кабинет" с домашней странице 
        - по нажатию кнопки "Войти в аккаунт" с домашней странице
        - по ссылке "Войти" со страницы регистрации
        - по ссылке "Войти" со страницы восстановления пароля
    2.5 Проверка входа в аккаунт
    2.6 Проверка выхода из аккаунта
3. test_3_transition - содержит 2 теста:
    3.1 проверка перехода в личный кабинет авторизованного пользователя
    3.2 проверка перехода в конструктор из личного кабинета авторизованного пользователя
4. test_4_crafted_burger содержит 3 теста:
    4.1 проверка перехода к булкам
    4.2 проверка перехода к соусам
    4.3 проверка перехода к начинкам
